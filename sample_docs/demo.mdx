# Fast-MD Showcase

Welcome to **Fast-MD**, the ultra-responsive desktop document reader built with **Dioxus 0.6** and **Rust**.

---

## 💡 MDX Callout Components

<Callout type="tip">
  **Pro-Tip**: You can drag and drop any `.md` or `.mdx` file or use `Ctrl+O` to open documents instantly.
</Callout>

<Warning>
  **Live Watcher**: Any changes saved in an external editor will update in this window in real time without flicker!
</Warning>

<Callout type="danger">
  **Zero Panics**: Built with strict Rust zero-panic safety guarantees (`unwrap_used = "deny"`).

## 🚀 Native Syntax Highlighting

```rust
// Rust implementation using Dioxus 0.6 Signals
use dioxus::prelude::*;

#[component]
pub fn Reader() -> Element {
    let doc = use_signal(|| "Markdown Content");
    
    rsx! {
        article {
            class: "prose dark:prose-invert",
            "{doc}"
        }
    }
}
```
